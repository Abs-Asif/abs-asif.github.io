# Personal Web Application

This repository contains the web application and tools for personal profiles, book editing, and content archiving.

## Endpoints & Services

- **Archive API Endpoint:** `https://backoffice.daily-bangladesh.com/api-en/archive` (Daily Bangladesh API)

## Routes

- `/` — Identity & Profiles information view
- `/book` — Book Editor & PDF Generator with Markdown/RST/AsciiDoc support

## Features

- Direct open access to identity profiles without password protection
- Markdown book management, PDF generation, page breaks, watermarking, and formatting options
- Built with React, Vite, Tailwind CSS, and TypeScript
